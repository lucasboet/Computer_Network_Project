# Computer Networks - Final Project 

This repository contains the final project for the Computer Networks course. 

The project is divided into two main components: a network packet encapsulation simulation and a multithreaded client-server chat application. 

## 🚀 Project Overview

### Part 1: Packet Encapsulation and Traffic Simulation
This section simulates the logical encapsulation of HTTP messages across the TCP/IP layers. 
* It reads Application Layer messages (GET/POST requests) from a CSV file. 
* Using pandas in a Jupyter Notebook, it wraps the data by adding Transport (Port 80), Network (IP addresses), and Link (MAC addresses) headers. 
* The generated network traffic is then captured and analyzed using Wireshark. 

### Part 2: Multithreaded Chat Application
A Chat Application built with TCP Sockets that allows multiple clients to communicate through a central server. 
* **Concurrency:** The server spawns a new thread for every connected client, supporting at least 5 simultaneous users. 
* **Message Routing:** The server maintains a mapping of connected users, allowing for private messaging between specific clients. 
* **Graphical User Interface (GUI):** A custom Tkinter GUI that allows users to easily send messages, view chat history, and select recipients without freezing the application. 

## 📂 Repository Structure

* `server.py`: Manages socket connections, multithreading, and message routing. 
* `client_gui.py`: The client-side application featuring a graphical interface. 
* `client.py`: Text-based client implementation. 
* `calculatur.py`: An auxiliary module for performing simple calculations. 
* `Lucas_Maor_http_input.csv`: Contains the initial HTTP messages required for the simulation. 
* `ComputerNetworkProject.ipynb`: Jupyter Notebook used to simulate the TCP/IP encapsulation process. 
* `Lucas_Maor_http_capture.pcap` & `capture.pcap`: Wireshark capture files containing the traffic generated by the simulation and the chat application, respectively. 
* `report.docx`: The full project documentation. 
* `requirements.txt`: Contains all the necessary Python dependencies to run the project.

## 🛠️ Installation and Execution

1. **Clone the repository and install dependencies:**
   ```bash
   git clone <your-repository-url>
   cd <repository-folder>
   pip install -r requirements.txt
   ```

**2. Running Part 1 (Encapsulation):**
Open ComputerNetworkProject.ipynb in your preferred Jupyter environment and run the cells sequentially to generate the simulated traffic.   

**3. Running Part 2 (Chat Application):**Start the Server: Open a terminal and run the server script. 

```bash
python server.py
```

Start the Clients: Open a new terminal window for each user you want to connect and run the GUI script.   

```bash 
python client_gui.py
```
Enter a unique username in the login window and click Connect.
